# FlatSync - Setup & Build Guide

Complete step-by-step guide to set up and run FlatSync from scratch.

## Prerequisites Checklist

- [ ] Flutter SDK 3.0+ installed (`flutter --version`)
- [ ] Dart 3.0+ installed (included with Flutter)
- [ ] Android SDK or iOS SDK installed
- [ ] At least 2 devices/emulators for testing sync
- [ ] Git installed (optional, for version control)

## Installation Steps

### Step 1: Create Flutter Project (if starting fresh)

```bash
# Create new Flutter project
flutter create --project-name flatsync .

# Navigate to project
cd flatsync
```

### Step 2: Update Dependencies

Replace the contents of `pubspec.yaml` with the dependencies section from the main README or use:

```bash
flutter pub get
```

### Step 3: Generate Isar Database Files

Isar requires code generation. Run:

```bash
flutter pub run build_runner build
```

This generates:

- `expense_model.g.dart` - Database schema
- Isar collections and queries

**Note:** If you get errors:

```bash
flutter pub run build_runner clean
flutter pub run build_runner build --delete-conflicting-outputs
```

### Step 4: Run the App

#### On Android Emulator

```bash
# Start emulator
flutter emulators --launch Pixel_6_API_32

# In another terminal, run app
flutter run -d emulator-5554
```

#### On Physical Android Device

```bash
# Connect device via USB
adb devices

# Run app
flutter run -d <device-id>
```

#### On iOS Simulator

```bash
# Start simulator
open -a Simulator

# Run app
flutter run
```

## Setting Up Multi-Device Sync Testing

### Option 1: Two Emulators

```bash
# Terminal 1: Start first emulator
flutter emulators --launch Pixel_6_API_32

# Terminal 2: Start second emulator
flutter emulators --launch Pixel_6_API_31

# Terminal 3: Run on first emulator
flutter run -d emulator-5554

# Terminal 4: Run on second emulator
flutter run -d emulator-5555

# To get device IDs:
adb devices
```

### Option 2: Emulator + Real Device

```bash
# Start emulator
flutter emulators --launch Pixel_6_API_32

# Connect real device via USB

# List all devices
flutter devices

# Run on each
flutter run -d emulator-5554
flutter run -d <real-device-id>
```

### Option 3: Two Real Devices

```bash
# Connect both devices via USB

# Verify both connected
adb devices

# Run on each
flutter run -d <device-1-id>
flutter run -d <device-2-id>
```

## Troubleshooting Setup

### Build Runner Issues

```bash
# If generation fails
flutter pub run build_runner clean
flutter pub run build_runner build --delete-conflicting-outputs

# Update dependencies
flutter pub upgrade
```

### Isar Database Issues

```bash
# Delete app data
adb shell pm clear com.example.flatsync
adb uninstall com.example.flatsync

# Reinstall
flutter run

# On iOS
rm -rf ~/Library/Containers/com.example.flatsync
```

### Dependency Issues

```bash
# Get latest compatible versions
flutter pub get

# Check outdated packages
flutter pub outdated

# Upgrade to latest
flutter pub upgrade

# Resolve conflicts
flutter pub upgrade --major-versions
```

### Code Generation Issues

If models don't work after editing expense_model.dart:

```bash
# Delete generated files
rm lib/src/data/models/expense_model.g.dart

# Regenerate
flutter pub run build_runner build

# If still errors, try:
flutter pub run build_runner build --delete-conflicting-outputs
```
